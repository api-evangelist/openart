# OpenArt

> OpenArt (https://openart.ai) is an all-in-one AI creation platform for generating and editing images, video, audio, and 3D content. It aggregates leading models (Seedance, Google Veo, Sora, GPT Image, Kling, and others) into a single workspace with tools for consistent character creation, world-building, and cinematic storytelling. For agents, OpenArt ships a hosted remote Model Context Protocol (MCP) server so AI assistants can generate images and video directly in a conversation.

This llms.txt was generated by the API Evangelist enrichment pipeline from the OpenArt public surface and the artifacts in this repository. OpenArt does not publish a conventional REST API/OpenAPI; its programmatic surface is the remote MCP server plus its OAuth 2.0 authorization service.
